## 📂 Repository Structure

The repository is divided into three main domains:

### 1. `Digital Projects/` *(Active)*
This directory contains my core hardware description and RTL design projects. It includes Verilog and Bluespec SystemVerilog (BSV) source files, testbenches, and complete Xilinx Vivado project directories targeting FPGA deployment.
* **Combinational Logic:** `Full_adder`, `4-bit_CLA_using_MUX` (Carry Lookahead Adder).
* **Sequential Logic:** `4-bitCounter`, `Mod 8 Ripple Counter`, `Shift Register`.
* **Advanced Modules:** `GCD` (Greatest Common Divisor hardware implementation), `BSV_Fibonacci` (Fibonacci sequence generator written in Bluespec), `BSV_RCA` (Ripple Carry Adder).

### 2. `Digital Software/`
This folder contains the executable files and environment for [Digital](https://github.com/hneemann/Digital), an easy-to-use digital logic designer and circuit simulator. I use this environment for rapid prototyping of logic gates and state machines before writing the actual HDL code.
* Includes cross-platform launchers (`Digital.exe`, `Digital.jar`, `Digital.sh`).

### 3. `Java/`
An archive of my foundational programming exercises focusing on algorithmic logic and basic application architecture. 
* Contains raw `.java` and compiled `.class` files for various mathematical and logical utilities.
